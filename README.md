# 🐹 또햄찌 공방 (Hamzzi Studio)

> **귀여운 또햄찌 사진으로 말풍선과 스티커를 더해 1초 만에 나만의 짤방을 만드는 고화질 웹 짤방 편집기**

---

- **프로젝트에 포함된 이미지(햄스터 및 헤드셋 자산 등)는 생성형 AI를 활용하여 예시로 제작된 것입니다.**

## ✨ 주요 기능 (Key Features)

1. **실시간 캔버스 편집 & 60FPS 마우스 드래그 인터랙션**
   - 캔버스 위의 문구, 말풍선, 스티커를 마우스 또는 터치로 자유롭게 드래그하여 원하는 위치에 배치
   - 마우스 휠을 통한 실시간 확대/축소(Zoom: 50% ~ 250%) 및 이미지 팬(Pan) 이동 지원

2. **호스트 파일 드래그 & 드롭 자동 업로드 (OS Explorer Drop)**
   - 내 컴퓨터의 파일 탐색기나 바탕화면에서 사진을 드래그하여 작업대나 업로드 영역에 놓으면 1초 만에 자동 고화질 로드
   - 드래그 진입 시 시각적인 발광 피드백 및 안내 오버레이 제공

3. **작업대 상시 고정 (Sticky Workstation Layout)**
   - 우측의 다양한 옵션(폰트, 스티커, 문구, 배경색 등)을 스크롤하면서 작업할 때도 중앙 미리보기 캔버스와 다운로드 바가 화면에 상시 고정되어 실시간 반영 모습을 눈앞에서 확인 가능

4. **14종 한국어 폰트 및 시각적 optgroup 분류**
   - **인기 짤방체**: 베이글 폰트(Bagel Fat One), 검은고딕(Black Han Sans), 배민 도현체, 배민 주아체
   - **귀여운 손글씨/다꾸체**: 동글체, 감자꽃체, 개구체, 나눔손글씨 펜체, 싱글데이체, 푸어스토리, 배민 연성체
   - **깔끔 고딕체**: Noto Sans KR, 고운 돋움체, 해바라기체

5. **40종 소품/감정 스티커 & 원터치 카테고리 탭**
   - 소품(8종), 효과(8종), 감정(8종), 음식(8종), 짤방(8종) 등 총 40종의 다채로운 스티커 제공
   - 상단 카테고리 필터 탭(`[전체] [소품] [효과] [감정] [음식] [짤방]`)으로 원하는 스티커 즉시 탐색

6. **6종 벡터 말풍선 및 부분 글자색 서식 지원**
   - 기본 말풍선, 둥근 말풍선, 생각 구름, 만화 외침, 각진 말풍선, 속삭임 말풍선 지원 및 내부 배경색 변경
   - 문구 입력란에서 드래그한 글자만 특정 색상으로 변경하는 인라인 컬러 서식(`[단어](#hex)`) 지원

7. **정돈된 모던 내보내기 툴바 (Export Toolbar)**
   - **저장 포맷 선택기**: `PNG`, `JPEG`, `⭐ 2K 고화질(2160px)` 선택 칩 제공
   - **원클릭 클립보드 복사**: 이미지 저장 없이 즉시 복사하여 카카오톡, 슬랙, 인스타그램에 `Ctrl + V`로 바로 전송

8. **여백 투명 배경 모드 (PNG)**
   - 여백 배경색 대신 투명 배경으로 저장하여 투명 스티커나 누끼 짤방으로 활용 가능

## 🛠 기술 스택 (Tech Stack)

- **Frontend Core**: 순수 HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Graphics & Rendering**: HTML5 Canvas 2D Context API (하드웨어 가속 기반 고성능 렌더러)
- **Typography**: Google Fonts CDN (14종 무료 라이선스 한국어 폰트)
- **Storage & State**: 브라우저 LocalStorage (내 템플릿 저장 및 JSON 백업/복원)
- **Zero Build Tools**: 별도의 `npm install`이나 빌드 과정 없이 `index.html`을 더블 클릭하여 즉시 실행 가능

## 🚀 실행 및 배포 방법

### 로컬 실행 (Local)
1. 본 리포지토리를 다운로드(Clone 또는 ZIP 풀기)합니다.
2. `index.html` 파일을 크롬, 엣지 등 최신 웹 브라우저로 더블 클릭하여 즉시 실행합니다.
   (Base64 이미지 데이터 내장으로 별도의 웹 서버 없이도 캔버스 보안 오류가 발생하지 않습니다.)

### GitHub Pages 배포 (1클릭 정적 배포)
1. 본 프로젝트를 GitHub 리포지토리에 푸시합니다.
2. 리포지토리의 **Settings** > **Pages** 메뉴로 이동합니다.
3. **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 지정한 후 **Save**를 클릭합니다.
4. 약 1분 후 제공되는 URL(예: `https://<username>.github.io/<repo-name>/`)로 전 세계 어디서든 접속 가능합니다.

## 📝 과제 제출 정보 (Submission Guide)

### 1. 짧은 확인 방법 4줄 (T03-C31)
1. **위치**: 웹 브라우저(크롬, 엣지 등) 새 시크릿 창에서 배포 URL(`https://<username>.github.io/hamzzi-studio/`)에 접속합니다.
2. **3단계 이내 행동**: ① 좌측에서 원하는 햄찌를 고르거나 사진을 드래그하여 올리고, ② 우측에서 원하는 문구를 입력한 뒤, ③ 중앙 하단의 `[PNG 다운로드]`를 클릭합니다.
3. **통과 모습**: 캔버스 미리보기와 100% 동일한 글자 크기, 위치, 줄바꿈을 가진 고화질 이미지 파일(`hamzzi-1x1.png`)이 즉시 다운로드됩니다.
4. **안 될 때 모습**: 지원하지 않는 파일(txt, pdf)을 넣으면 기존 작업이 유지된 채 상단에 주황색 경고 토스트가 표시됩니다.

### 2. AI와 나의 판단 3줄 (T03-C32)
1. **AI에게 맡긴 일**: Canvas 2D 하드웨어 가속 렌더링 수식 계산(비율 스케일링, 말풍선 꼬리 베지어 곡선 좌표 연산), 14종 Google Fonts 최적화 연동, Base64 CORS 방지 데이터 생성.
2. **학생이 직접 판단한 일**: 우측 패널 스크롤 시 중앙 캔버스가 사라지는 문제를 해결하기 위한 `Sticky Workstation Layout` 설계, 복잡했던 4개 다운로드 버튼을 1개의 모던 칩 셀렉터 툴바로 통합하는 UX 결정, 비영리 교육 목적 면책 조항 및 라이선스 정책 수립.
3. **AI 제안을 따르지 않은 일 (이유)**: 초기에 제안된 무거운 외부 CSS 라이브러리(Tailwind/Bootstrap)와 Canvas 라이브러리(Fabric.js)를 채택하지 않았습니다. 외부 빌드 도구 의존성 없이 GitHub Pages에서 단일 HTML 파일로 가볍고 안전하게 1초 만에 실행되도록 순수 Vanilla JS/CSS 구조를 고수하였습니다.
