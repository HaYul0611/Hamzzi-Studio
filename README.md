## ✨ 주요 기능 (Key Features)

### 1. 실시간 캔버스 편집 & 60FPS 마우스·터치 드래그
- 캔버스 위의 문구, 말풍선, 스티커, 배경 이미지를 마우스 또는 터치로 자유롭게 드래그하여 직관적으로 배치
- 마우스 휠 실시간 확대/축소(Zoom: 50% ~ 250%) 및 이미지 팬(Pan: -100 ~ 100) 이동 조절
- **사진 맞춤 모드**: 프레임을 꽉 채우는 `채우기(Cover)` 모드 및 여백을 캔버스 배경색으로 채우는 `맞춤(Contain)` 모드 지원

### 2. 다중 텍스트+말풍선 독립 추가 및 8방향 자유자재 꼬리 조작
- `+ 말풍선 추가` 버튼으로 여러 개의 말풍선과 문구를 독립적으로 생성·배치·개별 스타일링
- **8방향 자유 꼬리 조작**: 좌상단, 상단, 우상단, 우측, 우하단, 하단, 좌하단, 좌측 꼬리 방향 클릭 전환
- **피사체 지향 자동 꼬리 계산**: 말풍선을 캔버스에서 드래그하여 이동할 때 사진 피사체(중앙)를 향해 꼬리 방향 자동 최적화

### 3. 캔버스 직접 클릭 선택 및 직관적 삭제 (✖)
- 캔버스 위 스티커나 말풍선을 마우스로 직접 클릭하면 미려한 점선 선택 가이드라인 표시
- 테두리 우측 상단에 일체형 투명 `✖` 삭제 버튼이 표시되어 원클릭으로 불필요한 요소 즉시 삭제
- 키보드 `Delete` 또는 `Backspace` 단축키로 현재 선택된 아이템 간편 삭제

### 4. 글자 크기 슬라이더 & 키보드 숫자 직접 입력 양방향 동기화
- 글자 크기를 슬라이더로 조절함과 동시에, 옆의 `<input type="number">` 입력창을 통해 키보드로 원하는 픽셀(12px ~ 120px) 직접 입력 지원

### 5. 사진 자동 누끼 따기 (배경 투명화)
- 업로드한 사진의 배경을 인공지능 알고리즘으로 자동 감지하여 투명하게 제거하는 원클릭 누끼 따기 기능 탑재
- 누끼 제거 강도(허용 오차 5~80) 슬라이더 미세 조정 및 `원본 복원` 버튼 제공

### 6. 호스트 파일 드래그 & 드롭 자동 업로드 및 작업 자동 초기화
- 내 컴퓨터 탐색기나 바탕화면에서 사진을 드래그하여 놓으면 즉시 고화질 로드
- **스마트 작업 초기화**: 새 사진 업로드 시 이전 사진에서 작업하던 모든 스티커, 말풍선, 선택 박스가 깨끗하게 자동 초기화되어 새 작업 환경 제공

### 7. 사용자 지정 목표 파일 용량(KB) 맞춤 압축 다운로드
- **원하는 용량 맞춤 다운로드**: `[ 300 KB ]`, `[ 500 KB (권장) ]`, `[ 1 MB ]`, `[ 2 MB ]` 프리셋 및 `직접 입력(KB)` 지원
- **브라우저 이진 탐색 압축 엔진 (`Utils.compressToTargetSize`)**: 6회 이진 화질 튜닝 및 적응형 해상도 다운스케일링을 통해 사용자가 지정한 목표 용량 이하로 엄격히 맞추면서 최상의 선명도 유지

### 8. 24종 엄선 한국어 폰트 아코디언 드로어
- **인기 짤방체**: 베이글 폰트, 검은고딕, 배민 도현체, 배민 주아체, 잘풀리는오늘, 지마켓산스 등
- **귀여운 손글씨/다꾸체**: 동글체, 감자꽃체, 개구체, 나눔손글씨 펜체, 싱글데이체, 푸어스토리 등
- **깔끔 고딕/명조체**: Noto Sans KR, 고운 돋움체, 해바라기체, 나눔명조, 송명체 등
- 이모지 없이 순수 글꼴명만 깔끔하게 정돈된 슬라이딩 아코디언 드로어 UI

### 9. 40종 소품/감정 스티커 & 카테고리 탭
- 소품(8종), 효과(8종), 감정(8종), 음식(8종), 짤방(8종) 총 40종의 고화질 벡터 스티커
- 상단 카테고리 필터 탭으로 원하는 스티커를 원터치 탐색 및 배치

### 10. 6종 벡터 말풍선 및 부분 글자색 서식
- 기본 말풍선, 둥근 말풍선, 생각 구름, 만화 외침, 각진 말풍선, 속삭임 말풍선 지원
- 문구 입력란에서 드래그한 특정 단어만 다른 색으로 강조하는 인라인 컬러 서식(`[단어](#hex)`) 지원

### 11. 모던 통합 내보내기 툴바 (Export Toolbar)
- **저장 포맷**: `용량 최적화(맞춤 KB)`, `PNG`, `JPEG`, `WebP`, `⭐ 4K 초고화질(3840px)`
- **원클릭 클립보드 복사**: 파일 저장 없이 클립보드에 복사하여 카카오톡, 슬랙에 `Ctrl + V`로 즉시 붙여넣기
- **세 화면비 일치성**: 1:1(정사각형), 4:5(인스타 피드), 9:16(스토리/릴스) 비율 변환 지원

### 12. 템플릿 관리 (사용자 이름 CRUD, 날짜·시간 타임스탬프 & 강화된 JSON 백업/복원)
- **사용자 지정 템플릿 이름 생성 & 인라인 수정(Rename) CRUD**:
  - 저장 시 사용자가 원하는 템플릿 이름을 직접 입력하여 저장 가능 (미입력 시 캔버스 문구 자동 활용)
  - 템플릿 목록 카드에서 `[이름 수정]` 버튼을 통해 인라인 편집창으로 손쉽게 이름 변경(Rename) 및 `Enter` 저장
  - 현재 캔버스 작업 내용으로 템플릿을 즉시 갱신하는 `[덮어쓰기]` 및 화면 중앙 커스텀 컨펌 다이얼로그(`Utils.showConfirm`) 기반의 안전한 `[삭제]`
- **생성 및 최근 수정 날짜·시간(`YYYY.MM.DD HH:mm`) 자동 기록**:
  - 카드마다 종횡비, 폰트 크기와 함께 생성일시 및 최근 수정일시(`updatedAt`)를 선명하게 출력
- **고도화된 JSON 백업/복원 시스템**:
  - **유연한 입출력 지원**: `[💾 JSON 파일 다운로드]`, `[📋 클립보드 복사]`, `[📁 .json 파일 직접 열기]`
  - **복원 모드 선택**: 기존 데이터를 안전하게 보존하는 `기존 목록에 추가(병합, 권장)`와 `전체 덮어쓰기(교체)` 지원
  - **리치 알림 카드 및 시각적 피드백**: 성공 뱃지, 복원 모드 및 보관 수량 안내, 가져온 템플릿 이름 태그 칩 목록, `[내 템플릿 바로가기]` 링크 및 상단 토스트 알림 연동

## 🛠 기술 스택 (Tech Stack)

- **Frontend Core**: 순수 HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Graphics & Rendering**: HTML5 Canvas 2D Context API (하드웨어 가속 렌더링)
- **Image Compression**: HTML5 Canvas 기반 이진 탐색(Binary Search) 화질 최적화 엔진
- **Typography**: Google Fonts CDN (24종 무료 라이선스 한국어 폰트)
- **Storage & State**: 브라우저 LocalStorage (템플릿 CRUD 및 JSON 백업/복원)
- **Zero Build Tools**: `npm` 설치나 빌드 과정 없이 `index.html`을 열어 즉시 실행 가능한 100% 독립형 웹 앱

### 2. 짧은 확인 방법 4줄 (T03-C31 준수)
1. **위치**: 웹 브라우저(크롬, 엣지 등) 새 시크릿 창에서 배포 URL(`https://hayul0611.github.io/Hamzzi-Studio/`)에 접속합니다.
2. **3단계 이내 행동**: ① 좌측에서 원하는 햄찌를 고르거나 사진을 드래그하여 올리고, ② 우측에서 원하는 문구를 입력하거나 스티커를 추가한 뒤, ③ 중앙 하단의 `[용량 최적화 다운로드]` 또는 `[PNG 다운로드]`를 클릭합니다.

4. **안 될 때 모습**: 지원하지 않는 파일(txt, pdf 등)을 올리면 기존 작업이 그대로 안전하게 유지된 채 상단에 주황색 경고 토스트가 표시됩니다.

### 3. AI와 나의 판단 3줄 (T03-C32 준수)
1. **AI에게 맡긴 일**: Canvas 2D 하드웨어 가속 렌더링 수식 계산(비율 스케일링, 8방향 말풍선 꼬리 좌표 연산), 이진 탐색 기반 사용자 목표 용량 맞춤 압축 알고리즘(`compressToTargetSize`) 구현, 24종 Google Fonts 최적화 로딩.
2. **학생이 직접 판단한 일**: 사진 업로드 시 이전 스티커·말풍선이 남아 불편했던 UX를 감지하여 자동 초기화 로직 설계, 캔버스 직접 클릭 선택 및 우상단 투명 ✖ 버튼 일체화, 복잡한 다운로드 방식을 사용자 맞춤 목표 용량(KB) 칩 셀렉터로 간소화하는 제품 방향 결정.
3. **AI 제안을 따르지 않은 일 (이유)**: 무거운 외부 프레임워크(React/Vue)나 CSS 라이브러리(Tailwind), 캔버스 라이브러리(Fabric.js) 도입 제안을 거절하고, 빌드 도구 없이 GitHub Pages에서 1초 만에 실행되며 브라우저 호환성이 완벽한 순수 Vanilla HTML/CSS/JavaScript 구조를 고수하였습니다.
